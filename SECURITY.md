# Security Policy

## Supported Versions
We only support and patch the latest version of the code on the `main` branch.

## Reporting a Vulnerability
If you find a security vulnerability or a cryptographic flaw in this application, **please do not open a public Issue**. 

Instead, please report it securely by contacting the author directly via email:
📧 mrnoxxgithub@proton.me

We will respond as quickly as possible to investigate and fix the issue before making it public.
